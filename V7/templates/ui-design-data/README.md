# UI设计数据资源

此目录存放UI设计数据资源文件（CSV格式），供 `ui-design-system` 技能使用。

## 数据文件说明

| 文件名 | 内容说明 |
|--------|---------|
| `colors.csv` | 配色方案 |
| `styles.csv` | UI风格 |
| `typography.csv` | 字体搭配 |
| `products.csv` | 产品类型 |
| `landing.csv` | 落地页模式 |
| `ux-guidelines.csv` | UX最佳实践 |
| `app-interface.csv` | 应用界面 |
| `charts.csv` | 图表设计 |
| `design.csv` | 设计规范 |
| `draft.csv` | 草稿模板 |
| `google-fonts.csv` | Google字体 |
| `icons.csv` | 图标库 |
| `react-performance.csv` | React性能优化 |
| `ui-reasoning.csv` | UI推理规则 |
